Introduction

Around the year 1800, people already knew how to solve equations of the forms -

  • Linear Equations: ax+b=0ax + b = 0

  • Quadratic Equations: ax2+bx+c=0ax^2 + bx + c = 0

  • Cubic Equations: ax3+bx2+cx+d=0ax^3 + bx^2 + cx + d = 0

  • Quartic Equations: ax4+bx3+cx2+dx+e=0ax^4 + bx^3 + cx^2 + dx + e = 0

However, the general solution for equations of degree 5 or higher was not known. A young mathematician named Evariste Galois answered the question of the existence of a general solution for polynomial equations of degree 5 or higher, using a tool called groups.

Around the same time, Carl Friedrich Gauss introduced a technique called modular arithmetic, which laid the foundation for number theory. This technique shares a close relationship with groups.

The 1800s also saw a revolution in geometry. For over 2000 years, Euclidean Geometry was the only known geometry. However, mathematicians began to explore different geometries (specailly geometries on non-planar or curved surfaces). Groups became useful in studying these new geometries as well.

The formalization of groups by mathematicians supporting Galois and Gauss led to the birth of Group Theory and Abstract Algebra. Mathematicians realized that groups were very useful in studying various mathematical structures, and thus extended the idea of groups to other structures such as rings, fields, modules, vector spaces etc. It took years of effort by many mathematicians to formalize these structures and study their properties.

As time passed, the applications of these structures in various fields of mathematics and science became apparent. Today, it is used in computer science, cryptography, physics, chemistry, biology and many other fields.

This course aims to introduce the basic concepts of Group Theory, Ring Theory and some fundamental ideas in Abstract Algebra. We will explore the properties of these structures and their applications in various fields of mathematics and science.

Let us now analyze the similarities between these examples.

  1. Each of these examples has a set of objects that are considered (numbers of the clock, symmetries of the triangle, integers). We call these objects elements of a set.

  2. We have a way of combining two elements of the set to get another element of the set (addition on the clock, composition of symmetries, addition of integers). We call this way of combining elements an operation.

  3. All sets are closed under the operation defined on them (adding two numbers on the clock gives another number on the clock, composing two symmetries gives another symmetry, adding two integers gives another integer).

  4. The operation is associative (for any three numbers on the clock, adding them in any order gives the same result, composing three symmetries in any order gives the same result, adding three integers in any order gives the same result).

  6. 1.2 Groups and Operations

1.2.1 Definitions

Based on the observations from the previous section, we can now formally define groups and operations.

Definition 1.2.1.1 (Groups)

A group (G,*)(G, *) is a set GG equipped with a binary operation *:G×G→G* : G \times G \to G that satisfies the following properties:

  • Closure: For all a,b∈Ga, b \in G, the result of the operation a*ba * b is also in GG.

  • Associativity: For all a,b,c∈Ga, b, c \in G, (a*b)*c=a*(b*c)(a * b) * c = a * (b * c).

  • Identity Element: There exists an element e∈Ge \in G such that for every element a∈Ga \in G, e*a=a*e=ae * a = a * e = a.

  • Inverse Element: For each a∈Ga \in G, there exists an element b∈Gb \in G such that a*b=b*a=ea * b = b * a = e, where ee is the identity element.

It took years of effort to develop the formal definition of groups based on the most fundamental properties observed in various mathematical contexts. For example, the property of commutativity (i.e., a*b=b*aa * b = b * a for all a,b∈Ga, b \in G) is not included in the definition of groups, as there exist many important groups where this property does not hold. Groups where commutativity holds are called abelian groups, named after the mathematician Niels Henrik Abel. Similarly, a non-commutative group is called non-abelian.
Let us now formally define a binary operation.

Definition 1.2.1.2 (Binary Operation)

A binary operation on a set SS is a function *:S×S→S* : S \times S \to S that combines any two elements a,b∈Sa, b \in S to produce another element c∈Sc \in S, denoted as a*b=ca * b = c.

Let us consider some examples of binary operations.

  1. Addition on Integers: The operation of addition +:ℤ×ℤ→ℤ+ : \mathbb{Z} \times \mathbb{Z} \to \mathbb{Z} defined by (a,b)↦a+b(a, b) \mapsto a + b is a binary operation on the set of integers ℤ\mathbb{Z}.

  2. Composition of Symmetries: Consider a set XX equipped with some structure. Now, a symmetry of XX is a bijective function from XX to itself that preserves the structure of XX. The operation of composition of symmetries ∘:Sym(X)×Sym(X)→Sym(X)\circ : \text{Sym}(X) \times \text{Sym}(X) \to \text{Sym}(X) defined by (f,g)↦f∘g(f, g) \mapsto f \circ g is a binary operation on the set of symmetries Sym(X)\text{Sym}(X).

  3. Union and Intersection: Let SS be a non-empty set. Then, ∪\cup{} and ∩\cap{} are binary operations on the power set of SS, denoted by 𝒫(S)\mathcal{P}(S). We define the operations as follows: ∪:𝒫(S)×𝒫(S)→𝒫(S)\cup{} : \mathcal{P}(S) \times \mathcal{P}(S) \to \mathcal{P}(S) defined by (A,B)↦A∪B(A, B) \mapsto A \cup B ∩:𝒫(S)×𝒫(S)→𝒫(S)\cap{} : \mathcal{P}(S) \times \mathcal{P}(S) \to \mathcal{P}(S) defined by (A,B)↦A∩B(A, B) \mapsto A \cap B

  4. Matrix Multiplication:For n∈ℕ,n≥1n \in \mathbb{N}, n\geq 1, let GLn(ℝ)GL_n(\mathbb{R}) be the set of all invertible n×nn \times n matrices with real entries. Then, the operation of matrix multiplication ⋅:GLn(ℝ)×GLn(ℝ)→GLn(ℝ)\cdot : GL_n(\mathbb{R}) \times GL_n(\mathbb{R}) \to GL_n(\mathbb{R}) defined by (A,B)↦A⋅B(A, B) \mapsto A \cdot B is a binary operation on the set of invertible matrices GLn(ℝ)GL_n(\mathbb{R}).

1.2.2 Cayley Tables

Let S be a non-empty set and ** be a binary operation on S. We can represent the operation ** using a table called the Cayley table. The rows and columns of the table are labeled with the elements of S, and the entry in the row corresponding to element aa and the column corresponding to element bb is the result of the operation a*ba * b.
Let us consider the following example -
Let S = {±1,±i}\{ \pm 1, \pm i \}, where ii is the imaginary unit. We define a binary operation ** on S as follows -

** 11 −1-1 ii −i-i
11 11 −1-1 ii −i-i
−1-1 −1-1 11 −i-i ii
ii ii −i-i −1-1 11
−i-i −i-i ii 11 −1-1
Note 1.2.2.1

We note the following properties of the above Cayley table -

  1. We have 1 as the identity element, since 1*a=a*1=a1 * a = a * 1 = a for all a∈Sa \in S.

  2. Every row and every colum contain the identity element, 1⋅1=1,−1⋅−1=1,i⋅−i=1,−i⋅i=11 \cdot 1 = 1, -1 \cdot -1 = 1, i \cdot -i = 1, -i \cdot i = 1

  3. Asssociativity holds, i.e., (a*b)*c=a*(b*c)(a * b) * c = a * (b * c) for all a,b,c∈Sa, b, c \in S.

  4. The table is symmetric about the main diagonal, i.e., a*b=b*aa * b = b * a for all a,b∈Sa, b \in S. Thus, the operation is commutative.

  5. No duplicate elements appear in any row or column. If there existed duplicates, then there would be elements without inverses.

Based on the above properties, we can conclude that the set S with the operation ** forms an abelian group.

1.6 Lagrange’s Theorem

Definition 1.6.1 (Cosets)

This theorem has many applications in group theory and helps us understand the structure of groups and their subgroups.

Theorem 1.8.2 (Coset Homomorphism is bijective)

Let (G,⋆)(G, \star) be a group. Define ϕg:G→G\phi_g: G \to G by ϕg(x)=g⋆x\phi_g(x) = g \star x for some fixed element g∈Gg \in G. Then ϕg\phi_g is a bijective homomorphism. Morever, ϕg\phi_g is the identity map if and only if gg is the identity element of GG.

Proof

We first show that ϕg\phi_g is a homomorphism. For any x,y∈Gx, y \in G, we have: ϕg(x⋆y)=g⋆(x⋆y)\phi_g(x \star y) = g \star (x \star y) and ϕg(x)⋆ϕg(y)=(g⋆x)⋆(g⋆y)\phi_g(x) \star \phi_g(y) = (g \star x) \star (g \star y) Since GG is a group, we can use the associativity of the group operation to rearrange the elements. We have: (g⋆x)⋆(g⋆y)=g⋆(x⋆(g⋆y))=g⋆((x⋆g)⋆y)=g⋆(x⋆(g⋆y))=g⋆(x⋆y)(g \star x) \star (g \star y) = g \star (x \star (g \star y)) = g \star ((x \star g) \star y) = g \star (x \star (g \star y)) = g \star (x \star y) Thus, we have: ϕg(x⋆y)=ϕg(x)⋆ϕg(y)\phi_g(x \star y) = \phi_g(x) \star \phi_g(y) which shows that ϕg\phi_g is a homomorphism. Next, we show that ϕg\phi_g is injective. Suppose ϕg(x)=ϕg(y)\phi_g(x) = \phi_g(y) for some x,y∈Gx, y \in G. This means that g⋆x=g⋆yg \star x = g \star y. Since GG is a group, we can multiply both sides by the inverse of gg to get: g−1⋆(g⋆x)=g−1⋆(g⋆y)g^{-1} \star (g \star x) = g^{-1} \star (g \star y) Using the associativity of the group operation, we have: (g−1⋆g)⋆x=(g−1⋆g)⋆y(g^{-1} \star g) \star x = (g^{-1} \star g) \star y Since g−1⋆g=eGg^{-1} \star g = e_G, we have: eG⋆x=eG⋆ye_G \star x = e_G \star y which implies that x=yx = y. Therefore, ϕg\phi_g is injective. Finally, we show that ϕg\phi_g is surjective. Let z∈Gz \in G be an arbitrary element. We want to find an element x∈Gx \in G such that ϕg(x)=z\phi_g(x) = z. We can choose x=g−1⋆zx = g^{-1} \star z, which is an element of GG. Then we have: ϕg(g−1⋆z)=g⋆(g−1⋆z)=(g⋆g−1)⋆z=eG⋆z=z\phi_g(g^{-1} \star z) = g \star (g^{-1} \star z) = (g \star g^{-1}) \star z = e_G \star z = z Thus, for every element z∈Gz \in G, there exists an element x=g−1⋆zx = g^{-1} \star z such that ϕg(x)=z\phi_g(x) = z. Therefore, ϕg\phi_g is surjective. Since ϕg\phi_g is both injective and surjective, it is a bijection. Finally, we check if ϕg\phi_g is the identity map. We have: ϕg(x)=g⋆x\phi_g(x) = g \star x If ϕg\phi_g is the identity map, then we must have g⋆x=xg \star x = x for all x∈Gx \in G. In particular, if we take x=eGx = e_G, we have g⋆eG=eGg \star e_G = e_G, which implies that g=eGg = e_G. Conversely, if g=eGg = e_G, then we have: ϕg(x)=eG⋆x=x\phi_g(x) = e_G \star x = x for all x∈Gx \in G, which means that ϕg\phi_g is the identity map. Hence proved. ◻

We now move on to Cayley’s theorem, which states that every group is isomorphic to a subgroup of the symmetric group on some set. This theorem is fundamental in group theory as it allows us to represent abstract groups as groups of permutations, making them easier to study and understand.

1.9 Cayley’s Theorem

Theorem 1.9.1 (Cayley’s Theorem)

Every group GG is isomorphic to a subgroup of the symmetric group SGS_G on the set GG.

Proof

Let GG be a group. We want to show that there exists a subgroup of the symmetric group SGS_G that is isomorphic to GG. We can define a map f:G→SGf: G \to S_G by: f(g)(x)=g⋆xf(g)(x) = g \star x for all g,x∈Gg, x \in G. We need to check if ff is a group homomorphism. For any g1,g2∈Gg_1, g_2 \in G and x∈Gx \in G, we have: f(g1g2)(x)=(g1g2)⋆xf(g_1 g_2)(x) = (g_1 g_2) \star x and f(g1)(f(g2)(x))=f(g1)(g2⋆x)=g1⋆(g2⋆x)f(g_1)(f(g_2)(x)) = f(g_1)(g_2 \star x) = g_1 \star (g_2 \star x) Using the associativity of the group operation, we have: g1⋆(g2⋆x)=(g1g2)⋆xg_1 \star (g_2 \star x) = (g_1 g_2) \star x Thus, we have: f(g1g2)(x)=f(g1)(f(g2)(x))f(g_1 g_2)(x) = f(g_1)(f(g_2)(x)) which shows that ff is a group homomorphism. Next, we check if ff is injective. Suppose f(g1)=f(g2)f(g_1) = f(g_2) for some g1,g2∈Gg_1, g_2 \in G. This means that for all x∈Gx \in G, we have: f(g1)(x)=f(g2)(x)f(g_1)(x) = f(g_2)(x) which implies that g1⋆x=g2⋆xg_1 \star x = g_2 \star x for all x∈Gx \in G. In particular, if we take x=eGx = e_G, we have g1⋆eG=g2⋆eGg_1 \star e_G = g_2 \star e_G, which implies that g1=g2g_1 = g_2. Therefore, ff is injective. Since ff is a homomorphism and injective, it is an isomorphism onto its image. The image of ff is a subgroup of SGS_G that is isomorphic to GG. We show this by noting that the image of ff consists of all permutations of GG that can be expressed as left multiplication by elements of GG. Since ff is injective, the image of ff is isomorphic to GG. Therefore, we have shown that every group GG is isomorphic to a subgroup of the symmetric group SGS_G. Hence proved. ◻

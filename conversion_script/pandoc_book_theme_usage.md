## One-command batch script (Windows)

The batch script now performs the full pipeline automatically:

1. converts template-heavy `.tex` to pandoc-friendly LaTeX,
2. renders `tikzpicture` / `circuitikz` blocks to files in `images_folder`,
3. runs pandoc with section numbering and native HTML5 MathML output,
4. postprocesses HTML for theorem boxes, counters, list-of-theorems, and table wrappers.

From workspace root:

```powershell
conversion_script\convert_tex_to_html.bat tex_files\white\skolem.tex
```

Default output path for the above command:

```text
html\skolem.html
```

Optional output path:

```powershell
conversion_script\convert_tex_to_html.bat tex_files\white\skolem.tex html\skolem.html
```

After you pass a custom output once, the converter remembers that `.tex -> .html` link.
On later recompiles of the same `.tex`, you can omit the second argument and it will reuse the saved output path automatically.

Saved links are stored in:

```text
conversion_script\tex_html_links.map
```

Generated diagram files (for this example) are written to:

```text
html\images_folder\
```

## Interactive CLI launcher

Run the interactive launcher from workspace root:

```powershell
python conversion_script\notes_converter_cli.py
```

Main options in the prompt:

- file numbers (`1,3-5`): convert selected files with custom title/section prompts,
- `all`: recompile every `.tex` file discovered under `tex_files/white`,
- `linked` (or `mapped` / `m`): recompile only TeX files that already have saved TeX→HTML mappings,
- `link` (or `l`): link a TeX file to an existing HTML file without deleting or recreating files,
- `q`: quit.

### Build the EXE launcher

```powershell
conversion_script\build_notes_converter_exe.bat
```

This generates:

```text
dist\notes_converter.exe
```

## Desktop GUI launcher (HTML/CSS)

Run the GUI from workspace root:

```powershell
python conversion_script\notes_manager_gui.py
```

This starts a local backend and opens the GUI in your default browser.

The GUI includes both workflows:

- Converter tab (selected/all/linked modes, TeX→HTML linking, image base URL),
- TeX/HTML filter boxes for faster file picking,
- Quick TeX actions (select all, select mapped, clear),
- Live file stats (total TeX, mapped TeX, total HTML),
- Publisher tab (remote/branch/html-dir settings for HTML snapshot publish),
- Shared output log for command results, with copy/clear controls,
- Status line for current task outcome,
- Detailed per-file conversion progress logs (shows file index and target HTML path),
- Backend activity log file at `conversion_script/logs/notes_manager_gui.log`,
- Stop App button to shut down the local backend.

### Build the GUI EXE

```powershell
conversion_script\build_notes_manager_gui_exe.bat
```

This generates:

```text
dist\notes_manager_gui.exe
```

## Single-file conversion

From workspace root:

```powershell
pandoc tex_files/white/skolem_vanilla.tex -s --to=html5 --mathml --toc --toc-depth=3 --css=conversion_script/pandoc_book_themes.css --include-after-body=conversion_script/pandoc_theme_switcher.html -o tex_files/white/skolem.html
```

## Batch conversion (PowerShell)

```powershell
Get-ChildItem tex_files/white_vanilla -Filter *.tex | ForEach-Object {
  $out = [System.IO.Path]::ChangeExtension($_.FullName, ".html")
  pandoc $_.FullName -s --to=html5 --mathml --toc --toc-depth=3 --css=conversion_script/pandoc_book_themes.css --include-after-body=conversion_script/pandoc_theme_switcher.html -o $out
}
```

## Theme names

- `ivory` (Obsidian)
- `slate` (Nocturne, default)
- `forest` (Emerald Night)
- `midnight` (Midnight Indigo)

The selected theme is saved in browser local storage (`pandoc-book-theme`).

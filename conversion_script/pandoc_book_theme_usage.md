# Pandoc Book Theme Usage

This theme is designed for HTML5 output generated by pandoc.

## Files

- `conversion_script/pandoc_book_themes.css`
- `conversion_script/pandoc_theme_switcher.html`
- `conversion_script/convert_tex_to_html.bat`
- `conversion_script/temp_to_vanilla.py`
- `conversion_script/postprocess_pandoc_html.py`

## One-command batch script (Windows)

The batch script now performs the full pipeline automatically:

1. converts template-heavy `.tex` to pandoc-friendly LaTeX,
2. renders `tikzpicture` / `circuitikz` blocks to files in `images_folder`,
3. runs pandoc with section numbering and native HTML5 MathML output,
4. postprocesses HTML for theorem boxes, counters, list-of-theorems, and table wrappers.

From workspace root:

```powershell
conversion_script\convert_tex_to_html.bat tex_files\white\skolem.tex
```

Default output path for the above command:

```text
html\skolem.html
```

Optional output path:

```powershell
conversion_script\convert_tex_to_html.bat tex_files\white\skolem.tex html\skolem.html
```

Generated diagram files (for this example) are written to:

```text
html\images_folder\
```

## Single-file conversion

From workspace root:

```powershell
pandoc tex_files/white/skolem_vanilla.tex -s --to=html5 --mathml --toc --toc-depth=3 --css=conversion_script/pandoc_book_themes.css --include-after-body=conversion_script/pandoc_theme_switcher.html -o tex_files/white/skolem.html
```

## Batch conversion (PowerShell)

```powershell
Get-ChildItem tex_files/white_vanilla -Filter *.tex | ForEach-Object {
  $out = [System.IO.Path]::ChangeExtension($_.FullName, ".html")
  pandoc $_.FullName -s --to=html5 --mathml --toc --toc-depth=3 --css=conversion_script/pandoc_book_themes.css --include-after-body=conversion_script/pandoc_theme_switcher.html -o $out
}
```

## Theme names

- `ivory` (Obsidian)
- `slate` (Nocturne, default)
- `forest` (Emerald Night)
- `midnight` (Midnight Indigo)

The selected theme is saved in browser local storage (`pandoc-book-theme`).
